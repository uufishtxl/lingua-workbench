# Issue Tracker

## Platform

GitHub Issues

## Repository

`uufishtxl/lingua-workbench`

## External PRs as Triage Surface

No

## Usage

- Use `gh issue create` to create issues
- Use `gh issue list` to list issues
- Use `gh issue view <number>` to view an issue
- Use `gh issue close <number>` to close an issue

See [triage-labels.md](./triage-labels.md) for the label vocabulary.
